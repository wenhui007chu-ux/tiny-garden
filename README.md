# 🌱 手提小菜园 (Tiny Garden)

一款 2.5D 低模玩具盒风格的种田经营游戏。**所有 3D 模型、音乐、图形全部由代码生成**，不依赖任何美术或音频素材文件。

灵感来自 Steam 游戏《手提菜园》(Tiny Garden)。

## 运行

```bash
npm install
npm run dev
```

打开 http://localhost:5173 即可游玩。

> 小技巧：双击 `keep-alive.cmd` 可以守护开发服务器，它停了会自动重启。

## 玩法概览

### 种田
- **两层农田共 72 格**，二层每格需 1000 金币解锁
- **14 种作物**，从免费的红薯到 2500 的彩虹果
- **土壤三级**（普通/肥沃/黑金）按格升级，**水源三级**（水壶/洒水器/自动灌溉）
- **稀有品质**：种下时 5% 黄金（卖价 ×3）、15% 白银（×2），带镀层外观

### 环境与风险
- **昼夜循环**：现实 20 分钟为一天，夜晚生长减半
- **天气**：晴 65% / 暴雨 20% / 大旱 15%，恶劣天气收成「生长不良」半价并随机毁地
- **虫害**：成熟时 15% 生虫，可用杀虫剂或**徒手拍虫**（5% 中毒风险，不解毒会死亡）

### 加工与变现（倍率梯度）
| 方式 | 倍率 | 耗时 |
|------|------|------|
| 直接卖 | 1× | — |
| 🏭 工坊罐头 | 1.5× | 2 分钟 |
| 🍳 料理（50 道） | 3× | 6 分钟 |
| 🧬 杂交室（20 种） | ~5× | 10 分钟 |

### 建筑
- 🏠 **我的小屋**：26 件家具，每件可升到 **5 级**、五种外观（含鎏金 / 传说顶配）自由切换，支持拖拽自由摆放
- 📖 **图鉴大楼**：42 格基础图鉴 + 10 座个人金台
- 🐾 **宠物间**：20 只宠物（各含独立 3D 模型），10 种房间装饰，每种可升到 **5 级**
- 🧬 **杂交室**：3D 实验大厅，5 个培养罩
- 🍳 **料理工坊**、🛒 **商场**、🏦 **银行**、🎣 **水塘**（30 种会动的装饰）

### 便利功能
- 快捷键：`H` 收取 / `S` 售卖 / `R` 播种 / `W` 浇水
- 布局保存与一键播种、挂机模式、程序化背景音乐（5 首，可点播/循环）
- 内置**游戏百科**，13 个章节，数据从配置表实时生成

## 技术

- **Three.js** 渲染，**Vite** 构建
- `src/config.js` —— 所有数值表集中于此，调平衡只改这一个文件
- `src/meshes.js` —— 全部 3D 模型的程序化生成
- `src/music.js` —— Web Audio 实时合成的背景音乐
- 存档：localStorage + 开发服务器落盘备份（`saves/` 保留最近 24 份历史副本）
